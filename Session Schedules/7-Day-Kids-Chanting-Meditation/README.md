# 7-Day Kids Chanting & Silent Meditation

Gentle daily sessions for children from **Temple of Inner Wisdom** (Master Minood).

Each day: one short mantra + 15 minutes of silent sitting.

- Hub: `index.html`
- Days: `day-01.html` … `day-07.html`

**Mantras:**
1. Sahana Vavatu
2. Asato Ma Sadgamaya
3. Poornamada
4. Maha Mrityunjaya
5. Sarve Bhavantu
6. Shubham Karoti
7. Karpoora Gauram
