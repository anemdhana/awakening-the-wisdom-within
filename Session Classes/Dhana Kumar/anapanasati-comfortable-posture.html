1 · Comfortable Posture

Sit so the body can rest completely.

No force. No strain. Soft natural ease.

Comfort first — then the mind can settle.

2 · Scan the Whole Body

Closely watch every part of the body.

Shoulders · neck · back · hips · legs · jaw

Wherever there is tightness — adjust.

3 · The Ant-Bite Example

If an ant bites you, you know exactly where it is.

You go there and make that spot relax.

Use the same precision for every tiny discomfort in the body.

4 · Body Fades… Breath Remains

When no discomfort is left,

the body fades into the background.

Only the natural breath remains.

5 · If Discomfort Returns…

Body slowly “reappears” from the fade —

an alert that something needs adjusting.

Pause. Soften that place. Return to ease.

6 · Stay with the Breath Path

Attention rests only on natural breath.

Feel sensations inside the breath path —

as air moves in… and as it moves out.

7 · When Thoughts Appear

Thoughts will come — that is natural.

Simply be aware: “a thought is here.”

Gently return to the breath.

Aware → Return → Continue
